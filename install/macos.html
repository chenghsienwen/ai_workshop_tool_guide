前置需求確認
開始安裝前，請先確認這些項目
✓

確認 Gemini 可以正常使用

在瀏覽器開啟 gemini.google.com，用 Google 帳號登入（個人或公司帳號都可以），確認能正常對話、沒有被公司網路擋住。這是後續安裝 AI Agent 的必要條件。

✓

確認 macOS 已更新

點選左上角 蘋果選單 → 「關於此 Mac」，確認你的晶片版本（Apple Silicon M 系列或 Intel）與 macOS 版本。接著到 系統設定 → 「一般」→ 「軟體更新」，確認已安裝最新更新。

✓

準備帳號

請事先準備好以下帳號：

  • 🔵 Google 帳號（免費，用於 Gemini / Google Antigravity）
  • 🟣 Claude Pro 帳號（選用，如果你已有訂閱，可改用 Claude Desktop）
✓

開啟終端機（Terminal）

所有安裝指令都會在「終端機」中執行。開啟方式：

開啟終端機步驟

1. 按下 Command (⌘) + 空白鍵 開啟 Spotlight 搜尋

2. 輸入 Terminal（終端機）

3. 按 Enter 開啟

💡 不需要「系統管理員身分」開啟。之後有些指令會加上 sudo，執行後要求輸入你的 Mac 登入密碼（打字時不會顯示任何字元，是正常現象，打完按 Enter 即可）。

步驟 1：安裝 Node.js（LTS 版本）

下載並安裝 Node.js LTS

點選以下連結下載 macOS 安裝檔（.pkg，Apple Silicon 與 Intel Mac 通用），下載完成後雙擊開啟，一路點「繼續」，最後輸入你的 Mac 登入密碼授權安裝。

直接下載（macOS .pkg，Universal）

版本：v22.23.1（LTS）。需要其他版本可到 nodejs.org 選擇下載，或用 brew install node 安裝。

步驟 2：安裝 Python
AI 腳本執行環境 · 參考版本：Python 3.11.9 · 約需 5 分鐘
🏢 公司 Mac，無法自行安裝軟體？點此展開（IT 申請範本）
請在 Workshop 前 2～3 個工作天向 IT Help Desk 提交申請。

📋 IT Ticket 建議填寫內容（Python）：

- 軟體名稱：Python 3.x（官方版） - 下載來源：https://www.python.org（官方網站） - 用途：執行 AI Workshop 課程的 Python 腳本 - 需要權限：本機系統管理員密碼（macOS pkg 安裝授權）
1

下載並安裝 Python

macOS 內建的系統版 Python 版本較舊，請下載官方版安裝。點選以下連結下載安裝檔（.pkg），雙擊開啟，一路點「繼續」→ 輸入 Mac 密碼授權安裝。

直接下載（macOS .pkg，universal2）
https://www.python.org/ftp/python/3.11.9/python-3.11.9-macos11.pkg
⚠️
安裝完成後，Finder 會自動開啟一個 Python 3.x 資料夾（位於「應用程式」內），請雙擊執行裡面的 Install Certificates.command，安裝 SSL 憑證（避免之後用 pip 安裝套件時失敗）。

💡 macOS 上請習慣用 python3 / pip3（而非 python / pip）。

🧠
步驟 3：安裝 AI Agent
讓 AI 能直接讀寫專案資料夾裡的檔案 · 約需 5 分鐘
ℹ️ 跟純聊天的 AI 不同，這裡要裝的是能直接讀寫本機檔案的 AI Agent App：打開一個專案資料夾後，AI 可以直接幫你建立、修改、執行裡面的檔案。請依你是否已有 Claude Pro / Max 訂閱，選擇下面其中一種方案安裝（擇一即可，不需要兩個都裝）。

🆓 方案 A：Google Antigravity（沒有付費訂閱，用免費方案）

1

下載並安裝 Antigravity

https://antigravity.google

首頁會有下載按鈕，點選後選擇 Mac 版本下載 .dmg 檔，開啟後把 App 拖曳到「應用程式」資料夾。

❓ 打開時顯示「無法打開，因為來自未識別的開發者」？

這是正常的 macOS 安全機制（Gatekeeper），並非檔案損壞。在 Finder 中按住 Control 點按 App 圖示 → 選擇「打開」→ 再次確認「打開」；或到「系統設定」→「隱私權與安全性」找到提示點「強制打開」。只需要做一次。

2

用 Google 帳號登入

開啟 Antigravity，選擇用 Google 帳號登入（跟前置需求確認 Gemini 時用的帳號一樣即可，個人或公司帳號都可以）。

3

開啟專案資料夾，試著讓 AI 改檔案

「File」→「Open Folder」開啟你的 Workshop 專案資料夾，在 Agent 面板輸入指令，例如「建立一個 hello.py，內容印出 Hello World」，AI 會直接在資料夾中建立並執行檔案。

🏢 公司網路擋住 Google 登入畫面？點此展開

如果登入卡住或顯示授權失敗，通常是公司防火牆封鎖了 accounts.google.com 的連線，不是你操作錯誤。請聯繫 IT Help Desk，說明需要開放 Google 帳號登入（OAuth）的網路存取權限。

💳 方案 B：Claude Desktop（已有 Claude Pro / Max 訂閱）

1

下載並安裝 Claude Desktop

https://claude.ai/download

選擇 Mac 版本下載並安裝，開啟後用 Claude Pro / Max 帳號登入。

2

安裝 Filesystem 擴充功能

登入後到「設定」→「擴充功能（Extensions）」，找到 Filesystem 並安裝，安裝時選擇要授權讀寫的專案資料夾。

3

試著讓 AI 改檔案

在對話框輸入類似「幫我在專案資料夾建立 hello.py，內容印出 Hello World」，Claude 會直接在你授權的資料夾中建立檔案。

⚠️ Claude Desktop 沒有免費方案，需要 Claude Pro（$20/月）或 Max（$100/月）訂閱才能使用。

步驟 4：建立 Slidev 簡報
用 Markdown 寫投影片 · 需要 Node.js（步驟 1） · 約需 5 分鐘

Slidev 是用 Markdown 寫投影片的簡報工具，支援即時預覽，適合搭配 AI CLI 快速產生簡報內容。

1

建立並啟動 Slidev 專案

在終端機中，切換到想放專案的資料夾（例如 cd ~/Documents），執行：

Terminal
$ npm init slidev@latest

依提示輸入專案名稱（例如 my-slides），是否安裝套件選 Yes。完成後：

Terminal
$ cd my-slides
$ npm run dev

瀏覽器會自動開啟 http://localhost:3030。投影片內容在專案裡的 slides.md，用 Antigravity（或任何文字編輯器）編輯存檔後畫面會即時更新。停止伺服器按 Control (⌃) + C。若跳出「是否允許『node』接受連入的網路連線」，點選允許即可。

2

安裝自訂主題與範例簡報

從 課程雲端資料夾（Dropbox） 下載主題檔 slidev-theme-proav-0.0.7.tgz 與範例 slides.md，兩個檔案都放進專案資料夾（slides.md 直接取代原本的檔案）。接著在專案資料夾中執行：

Terminal
$ npm install ./slidev-theme-proav-0.0.7.tgz

瀏覽器畫面會即時更新；若開發伺服器沒在執行，重新執行 npm run dev 即可。

成功畫面：主題安裝完成後，瀏覽器中的第一頁投影片應該長這樣（ViewSonic Pro AV 封面）
✅
最終驗證清單
確認所有工具都已正確安裝

在終端機中執行以下指令，確認 Node.js 有回應版本號碼（Slidev 需要用到）：

Terminal
$ node -v && npm -v
# 應顯示類似 v22.x.x / 10.x.x

點選項目打勾確認完成：

  • Node.js LTS 已安裝，node -v 顯示 v22.x.x
  • Python 已安裝（Finder「應用程式」看得到 Python 3.x 資料夾即可）
  • AI Agent 已安裝並登入（Google Antigravity 或 Claude Desktop 擇一）
  • 已實際測試 AI Agent 能直接在專案資料夾建立／修改檔案
  • Slidev 專案已建立，npm run dev 可在 http://localhost:3030 開啟簡報
  • 自訂主題 slidev-theme-proav 已安裝，範例 slides.md 已放入專案並正常顯示

常見問題排除
❓ 輸入指令後出現「command not found」

PATH 設定尚未生效。請完全關閉終端機後重新開啟（不是只關掉分頁），或執行 source ~/.zshrc 重新載入設定。如果還是不行，請重新啟動電腦。

❓ 應用程式顯示「無法打開，因為來自未識別的開發者」

這是 macOS 的 Gatekeeper 安全機制，不代表檔案有問題。在 Finder 中按住 Control 點按該 App → 選擇「打開」；或到「系統設定」→「隱私權與安全性」，找到提示並點「強制打開」。

❓ npm 安裝全域套件出現「permission denied」錯誤

不建議用 sudo npm install -g ... 解決，容易造成後續權限混亂。優先確認你是用官方 .pkg 或 Homebrew 安裝的 Node.js（而非依賴系統權限），必要時可考慮改用 nvm 管理 Node 版本。
