AI 工具安裝指南

⚙️
前置需求確認
✓

取得系統管理員權限

安裝過程需要系統管理員權限，請先與 IT 聯繫，說明需要安裝 AI 環境所需的軟體（Node.js、Python），需要系統管理員權限。待 IT 提供方法後，再進行後面的安裝步驟。

步驟 1：登入 Gemini
1

用 Google 帳號登入 Gemini

在瀏覽器開啟 gemini.google.com，用 Google 帳號登入（個人或公司帳號都可以），確認能正常對話即可。

步驟 2：安裝 Node.js
AI 寫本地端小工具常用的環境之一
🔑 請確認是否已完成前置需求：取得系統管理員權限。
1

下載並安裝 Node.js

點擊以下連結從官網下載安裝檔，下載完成後雙擊開啟進行安裝。

https://nodejs.org/dist/v22.23.1/node-v22.23.1-x64.msi
步驟 3：安裝 Python
AI 寫本地端小工具常用的環境之一
🔑 請確認是否已完成前置需求：取得系統管理員權限。
1

下載並安裝 Python

點擊以下連結從官網下載安裝檔，下載完成後雙擊開啟進行安裝。

https://www.python.org/ftp/python/3.11.9/python-3.11.9-amd64.exe
⚠️
安裝過程請務必勾選 Add Python to PATH 再點「Install Now」，否則之後在命令提示字元中會因為找不到 python 指令而無法使用。
步驟 4：安裝 AI Agent
讓 AI 能直接讀寫專案資料夾裡的檔案
ℹ️ 跟純聊天的 AI 不同，這裡要裝的是能直接讀寫本機檔案的 AI Agent App：打開一個專案資料夾後，AI 可以直接幫您建立、修改、執行裡面的檔案。請確認您是否已有 Claude 訂閱方案，選擇下面其中一種方案安裝。

🆓 方案 A：無 Claude 方案，安裝 Google Antigravity

1

下載並安裝 Antigravity

https://antigravity.google.com

於官網下載 Windows 版本並安裝。

❓ 安裝時顯示「Windows 已保護您的電腦」？

此為 Windows SmartScreen 對較新軟體的預設警告，點選視窗中的「其他資訊」，再點「仍要執行」即可繼續安裝。

2

用 Google 帳號登入

開啟 Antigravity，選擇用 Google 帳號登入步驟 1 的 Google 帳號即可。

3

選擇任意專案資料夾，試著讓 AI 改檔案

「File」→「Open Folder」開啟你的 Workshop 專案資料夾，在 Agent 面板輸入指令，例如「建立一個 hello.py，內容印出 Hello World」，AI 會直接在資料夾中建立並執行檔案。

❓ 無法進入 Google 登入畫面？

如果登入卡住或顯示授權失敗，可能是公司網路防火牆封鎖了 accounts.google.com 的連線。請聯繫 IT，說明需要開放 Google 帳號登入的網路存取權限。

💳 方案 B：已有 Claude 方案，安裝 Claude Desktop

1

下載並安裝 Claude Desktop

https://claude.ai/download

於官網下載 Windows 版本並安裝。

2

用 Claude 帳號登入

開啟 Claude Desktop，選擇用 Claude 帳號登入。

3

選擇任意專案資料夾，試著讓 AI 改檔案

在對話框輸入類似「幫我在專案資料夾建立 hello.py，內容印出 Hello World」，Claude 會直接在你授權的資料夾中建立檔案。

步驟 5：建立 Slidev 簡報專案
用 Markdown 寫投影片的工具

Slidev 是用 Markdown 寫投影片的簡報工具，支援即時預覽，適合搭配 AI CLI 快速產生簡報內容。

1

建立空資料夾，並在該資料夾開啟命令提示字元

用檔案總管建立一個空白資料夾，作為簡報專案的位置（名稱可自訂，例如 my-slides）。進入這個資料夾後，點一下視窗上方的網址列，直接輸入 cmd 後按 Enter，就會開啟一個已經切換到該資料夾路徑的命令提示字元視窗。

2

建立並啟動 Slidev 專案

在命令提示字元中執行：

命令提示字元
> npm init slidev@latest # 安裝並初始化 Slidev 範例專案

依提示輸入專案名稱（例如 my-slides），是否安裝套件選 Yes。完成後：

命令提示字元
> cd my-slides # 切換到 Slidev 建立的專案資料夾
> npm run dev # 啟動 Slidev 專案
❓ 跳出「Windows Defender 防火牆已封鎖此應用程式的部分功能」？

此為 Windows 安全機制確認是否允許執行 Slidev 啟動本地端伺服器的簡報模式，點選「允許存取」即可。

瀏覽器會自動開啟 http://localhost:3030 顯示簡報檔，編輯 slides.md 的內容並存檔後，畫面會即時更新。

3

安裝 ProAV 主題與範例簡報檔

從 Slidev 課程檔 下載主題檔 slidev-theme-proav-0.0.7.tgz 與範例簡報 slides.md，兩個檔案都放進專案資料夾（slides.md 直接取代原本的檔案）。接著在命令提示字元中執行：

命令提示字元
> npm install .\slidev-theme-proav-0.0.7.tgz # 安裝 ProAV 主題包

瀏覽器畫面會即時更新，並顯示如下 ProAV 主題簡報：

最終驗證清單
1

開啟命令提示字元

按下鍵盤上的 Windows 鍵，輸入 cmd 後按 Enter 開啟。

2

確認 Node.js 環境安裝完成

在命令提示字元中執行指令確認版本：

命令提示字元
> node -v # 應顯示 Node.js 版本號
> npm -v # 應顯示 npm（Node.js 套件管理器）版本號
❓ 顯示「不是內部或外部命令」？

代表 PATH 尚未生效。請先完全關閉命令提示字元後重新開啟（不是最小化，而是關掉再開），若仍不行請重新啟動電腦。都試過還是不行的話，用以下方式手動把路徑加進 PATH，一般帳號就能自己完成、不需要 IT 協助：

1

開啟環境變數設定視窗

同時按下 Win + R 打開「執行」視窗，貼上以下指令並按 Enter：

Win + R
rundll32.exe sysdm.cpl,EditEnvironmentVariables

這個指令會跳過需要系統管理員權限的「系統內容」視窗，直接開啟「環境變數」設定視窗。

2

編輯「使用者變數」裡的 Path

在視窗上半部「〇〇的使用者變數」（不是下半部的「系統變數」）找到 Path 這一列，點選後按「編輯」→「新增」，貼上 Node.js 的安裝路徑（預設為 C:\Program Files\nodejs\）。

3

存檔並重開命令提示字元

按「確定」關閉所有「環境變數」視窗，接著完全關閉並重新開啟命令提示字元，指令就能正常使用了。

3

確認 Python 環境安裝完成

在命令提示字元中執行指令確認版本：

命令提示字元
> python --version # 應顯示 Python 版本號
❓ 沒有反應，或跳出 Microsoft Store？

通常是安裝時沒有勾選 Add Python to PATH。請到「設定」→「應用程式」→「進階應用程式設定」→「應用程式執行別名」，將 python.exe 與 python3.exe 的別名關閉，重新開啟命令提示字元再試一次。若仍不行，請回到步驟 3 重新安裝一次並記得勾選該選項。
