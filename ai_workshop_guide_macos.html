開啟終端機（Terminal）

所有安裝指令都會在「終端機」中執行。開啟方式：

開啟終端機步驟

1. 按下 Command (⌘) + 空白鍵 開啟 Spotlight 搜尋

2. 輸入 Terminal（終端機）

3. 按 Enter 開啟

💡 也可以從「Finder」→「應用程式」→「工具程式」找到「終端機」。macOS 預設 shell 為 zsh。
⚠️ 不需要用「系統管理員身分」開啟終端機。當某個步驟需要系統權限時，指令前面會加上 sudo，執行後會要求輸入你目前登入 Mac 的密碼（打字時畫面不會顯示任何字元，這是正常現象，直接打完按 Enter 即可）。

步驟 1：安裝 Node.js（LTS 版本）
Codex CLI 與 Claude Code 的執行環境 · 約需 5 分鐘
🏢
公司電腦用戶請注意：需先向 IT 申請安裝權限
由 MDM（如 Jamf）管理的公司 Mac，通常限制自行安裝軟體或需要系統管理員密碼。請在 Workshop 前 2～3 個工作天向 IT Help Desk 提交申請，避免當天無法安裝。

📋 IT Ticket 建議填寫內容：

主旨：申請安裝 Node.js LTS — AI Workshop 使用

內容：

您好， 我將參加 [日期] 的 AI Workshop， 課程需要在本機安裝以下軟體： - 軟體名稱：Node.js LTS - 下載來源：https://nodejs.org（官方網站） - 用途：執行 AI CLI 工具（Codex CLI / Claude Code） - 需要權限：本機系統管理員密碼（macOS pkg 安裝授權） 請問能否協助開放安裝權限，或由 IT 協助預先安裝？ 謝謝！
1

下載 Node.js LTS 安裝檔

點選以下連結直接下載 macOS 安裝檔（.pkg，Universal，Apple Silicon 與 Intel Mac 都適用）：

直接下載（macOS .pkg，Universal）
https://nodejs.org/dist/v22.23.1/node-v22.23.1.pkg

版本：v22.23.1（LTS "Jod"）。若需要其他版本，可改前往官方網站 https://nodejs.org 選擇下載。

💡 為什麼選 LTS？ LTS（長期支援版）更穩定，與大部分 AI 工具的相容性最好。官方 .pkg 為 Universal 安裝檔，不需另外選擇晶片版本。
2

執行安裝程式

下載完成後，雙擊 .pkg 安裝檔，然後：

  • 點「繼續」→「繼續」→ 接受授權條款
  • 安裝路徑保持預設，直接繼續
  • 點「安裝」，系統會跳出視窗要求輸入你的 Mac 登入密碼來授權安裝
  • 等待安裝完成，點「關閉」
macOS Installer.app — Node.js v22.23.1 安裝精靈（一路點「繼續」即可）
3

驗證安裝成功

安裝完成後，關閉並重新開啟終端機，輸入：

Terminal
$ node -v
# 應顯示類似 v22.x.x（參考版本：v22.23.1）

$ npm -v
# 應顯示類似 10.x.x
✅ 看到版本號碼代表 Node.js 已成功安裝！
💡 習慣用 Homebrew 的使用者，也可以改用 brew install node 安裝，效果相同。

步驟 2：安裝 Visual Studio Code
主力程式碼編輯器 · 約需 3 分鐘
1

下載 VS Code

前往官方網站下載：

https://code.visualstudio.com

首頁中央會有藍色的大型下載按鈕：

⬇ Download for Mac

它會自動偵測你的晶片版本（Apple Silicon 或 Intel）並提供對應的 .zip 下載檔

2

安裝 VS Code

下載的是壓縮檔，請依序操作：

  • 在「下載項目」中雙擊 .zip 檔自動解壓縮，得到 Visual Studio Code.app
  • 把它拖曳到 Finder 側邊欄的「應用程式」（Applications）資料夾
  • 之後就可以在啟動台（Launchpad）或「應用程式」資料夾中打開它
⚠️
首次開啟時，如果出現「無法打開，因為來自未識別的開發者」或「Apple 無法檢查是否含有惡意軟體」，這是正常的 macOS 安全機制（Gatekeeper），並非檔案損壞：
  • 在 Finder 中按住 Control 點按 App 圖示 → 選擇「打開」→ 再次確認「打開」
  • 或到「系統設定」→「隱私權與安全性」，捲到底找到提示訊息，點「強制打開」
這個步驟只需要做一次。
macOS Gatekeeper 警告：出現此視窗時，請到「系統設定」→「隱私權與安全性」點「強制打開」
3

把 code 指令加入 PATH（重要）

跟 Windows 版不同，macOS 版 VS Code 預設不會自動把 code 指令加進終端機。請手動設定一次：

  • 開啟 VS Code，按 ⌘ + Shift + P 開啟命令選擇區
  • 輸入 Shell Command: Install 'code' command in PATH 並按 Enter 選擇它
⚠️ 沒做這一步的話，之後在終端機輸入 code . 會出現「command not found」。
4

安裝推薦擴充功能

在 VS Code 中按 ⌘ + Shift + X 開啟擴充功能面板，搜尋並安裝：

🌏 Chinese (Traditional) Language Pack — 中文介面
🤖 GitHub Copilot（可選）— AI 輔助寫程式

步驟 3：安裝 Python
AI 腳本執行環境 · 參考版本：Python 3.11.9 · 約需 5 分鐘
🏢
公司電腦用戶請注意：需先向 IT 申請安裝權限
請在 Workshop 前 2～3 個工作天向 IT Help Desk 提交申請，並在 IT Ticket 中加入以下資訊：

📋 IT Ticket 建議填寫內容（Python）：

- 軟體名稱：Python 3.x（官方版） - 下載來源：https://www.python.org（官方網站） - 用途：執行 AI Workshop 課程的 Python 腳本 - 需要權限：本機系統管理員密碼（macOS pkg 安裝授權）
💡 macOS 通常已內建一個系統版 Python（供作業系統內部使用），版本較舊、不建議拿來開發。請依下方步驟安裝官方版本。
1

下載 Python 安裝檔

點選以下連結直接下載 macOS 安裝檔（.pkg，universal2，同時支援 Apple Silicon 與 Intel Mac）：

直接下載（macOS .pkg，universal2）
https://www.python.org/ftp/python/3.11.9/python-3.11.9-macos11.pkg

版本：Python 3.11.9。若需要其他版本，可改前往官方網站 https://www.python.org/downloads/macos/ 選擇下載。

💡 本指南的參考版本原為 Python 3.10.12，但 python.org 已停止為 3.10.x 系列提供 macOS 安裝檔，故改用 Python 3.11.9（同樣穩定，相容性良好）。
2

執行安裝程式並完成憑證設定

雙擊下載的 .pkg 安裝檔，一路點「繼續」→ 接受授權條款 → 輸入 Mac 密碼授權安裝 → 完成。

⚠️
安裝完成後，Finder 會自動開啟一個 Python 3.x 資料夾（位於「應用程式」內），裡面請雙擊執行以下腳本：
  • Install Certificates.command — 安裝 SSL 憑證，避免之後用 pip 安裝套件時失敗
Finder：應用程式 > Python 3.11 — 雙擊「Install Certificates.command」安裝 SSL 憑證
3

驗證安裝成功

安裝完成後，關閉並重新開啟終端機，輸入：

Terminal
$ python3 --version
# 應顯示類似 Python 3.x.x（參考版本：Python 3.11.9）

$ pip3 --version
# 應顯示 pip 版本號
💡 macOS 上請習慣使用 python3 / pip3（而非 python / pip），因為 python 這個名稱通常指向系統內建的舊版本，或根本不存在。
✅ 看到版本號碼代表 Python 已成功安裝！
💡 習慣用 Homebrew 的使用者，也可以改用 brew install python 安裝。

步驟 4：安裝 Codex CLI（OpenAI）
免費 · 需要 ChatGPT 帳號 · 約需 3 分鐘
✅ 完全免費！ 用 ChatGPT 免費帳號即可登入使用 Codex CLI，無需信用卡。
🏢
公司電腦用戶請注意：網路防火牆可能封鎖 Codex CLI
即使安裝成功，公司的網路安全設定可能會在你嘗試登入時顯示以下錯誤畫面。若出現這些症狀，請聯繫 IT Help Desk 申請開放網路存取權限。

症狀 1：登入時瀏覽器顯示「Sign-in could not be completed」

瀏覽器畫面：公司防火牆封鎖 OpenAI 登入時，會出現此 token_exchange_failed 錯誤

原因：公司防火牆封鎖了 OpenAI OAuth 認證伺服器（auth.openai.com）的連線。

症狀 2：端點安全軟體（如 CrowdStrike Falcon for Mac、Jamf Protect）跳出封鎖警告

端點安全軟體（如 CrowdStrike Falcon）封鎖 codex 對外連線時，會出現此通知

原因：公司端點安全軟體封鎖了 codex 執行檔的對外連線。

📋 IT Ticket 建議填寫內容（Codex CLI 網路權限）：

主旨：申請開放 Codex CLI 網路存取 — AI Workshop 使用 您好， 我在使用 AI Workshop 的 Codex CLI 工具時， 遭遇公司安全政策封鎖，出現以下錯誤： - 錯誤 1：瀏覽器顯示「Sign-in could not be completed」 （token_exchange_failed，無法連線至 auth.openai.com） - 錯誤 2：端點安全軟體封鎖 codex 對外連線 需要開放的網路存取： - auth.openai.com（OAuth 認證） - api.openai.com（API 呼叫） - 應用程式：codex（終端機執行檔，OpenAI OpCo, LLC） 謝謝！
1

開啟終端機

一般權限即可，不需要 sudo。

2

執行安裝指令

在終端機中貼上並執行以下指令：

Terminal
curl -fsSL https://chatgpt.com/codex/install.sh | sh
💡 安裝完成後，關閉並重新開啟終端機，讓 PATH 設定生效。習慣用 Homebrew 的使用者也可以改用 brew install --cask codex，或用 npm install -g @openai/codex（需先完成步驟 1 的 Node.js 安裝）。
3

驗證版本並首次登入

重新開啟終端機後，先確認版本：

Terminal
$ codex --version
# 應顯示類似 codex-cli x.x.x（參考版本：codex-cli 0.142.2）

確認版本後，輸入 codex 啟動並登入：

Terminal
$ codex

首次執行時，會提示你登入 ChatGPT 帳號，瀏覽器會自動開啟讓你完成授權。登入後即可開始使用！

Codex CLI 使用方式

登入後，在 Codex 的互動介面中，你可以輸入像這樣的自然語言指令：

codex> 建立一個 Python 的 Hello World 程式
# Codex 會直接幫你建立檔案並執行

Google 已在 2026/6/18 將 Gemini CLI 替換為 Antigravity CLI（指令為 agy）。如果你之前安裝過 Gemini CLI，請改安裝此新版本。

症狀 1：登入時瀏覽器顯示 Google OAuth 授權錯誤或無法完成

端點安全軟體（如 Jamf Protect）封鎖 agy 對外連線時，會出現此通知

原因：公司端點安全軟體封鎖了 agy 執行檔的對外連線至 Google API。

📋 IT Ticket 建議填寫內容（Antigravity CLI 網路權限）：

執行安裝指令

Terminal

Terminal
$ open -e ~/.zshrc

Terminal
$ source ~/.zshrc

步驟 7：建立 Slidev 簡報
用 Markdown 寫投影片 · 需要 Node.js（步驟 1） · 約需 5 分鐘
ℹ️
Slidev 是什麼？
Slidev 是為開發者設計的簡報工具：投影片用 Markdown 撰寫、支援程式碼高亮與即時預覽，非常適合搭配 AI CLI 工具快速產生與修改簡報內容。
1

建立新的 Slidev 專案

在終端機中，先切換到你想放專案的資料夾（例如 cd ~/Documents），然後執行：

Terminal
$ npm init slidev@latest

依照精靈提示操作：輸入專案名稱（例如 my-slides）→ 詢問是否安裝相依套件時選 Yes（套件管理器選 npm）。

💡 第一次執行會先詢問是否安裝 create-slidev 套件，按 Enter 同意即可。
2

啟動簡報開發伺服器

建立完成後精靈會詢問是否立即啟動；若選擇稍後啟動，或之後要重新開啟簡報，切換到專案資料夾執行：

Terminal
$ cd my-slides
$ npm run dev

瀏覽器會自動開啟 http://localhost:3030 顯示簡報。投影片內容都在專案裡的 slides.md，用 VS Code 編輯存檔後，瀏覽器畫面會即時更新。

💡 要停止伺服器，回到終端機按 Control (⌃) + C。簡報做好後可用 npm run export 匯出 PDF，或 npm run build 產出可部署的靜態網站。
3

安裝自訂主題 slidev-theme-proav

先從 課程雲端資料夾（Dropbox） 下載主題檔 slidev-theme-proav-0.0.7.tgz，放進專案資料夾（與 package.json 同一層），接著用 VS Code 開啟 package.json，在 dependencies 區塊中加入以下這行（記得補上前一行結尾的逗號）：

package.json — dependencies
"slidev-theme-proav": "file:./slidev-theme-proav-0.0.7.tgz"

存檔後，在專案資料夾中執行安裝：

Terminal
$ npm install
💡 也可以直接執行 npm install ./slidev-theme-proav-0.0.7.tgz，npm 會自動把上面那行加進 package.json。
4

下載範例簡報

常見問題排除
❓ 輸入指令後出現「command not found」

PATH 設定尚未生效。請完全關閉終端機後重新開啟（不是只關掉分頁），或執行 source ~/.zshrc 重新載入設定。如果還是不行，請重新啟動電腦。

❓ 應用程式顯示「無法打開，因為來自未識別的開發者」

這是 macOS 的 Gatekeeper 安全機制，不代表檔案有問題。在 Finder 中按住 Control 點按該 App → 選擇「打開」；或到「系統設定」→「隱私權與安全性」，找到提示並點「強制打開」。

❓ npm 安裝全域套件出現「permission denied」錯誤

不建議用 sudo npm install -g ... 解決，容易造成後續權限混亂。優先確認你是用官方 .pkg 或 Homebrew 安裝的 Node.js（而非依賴系統權限），必要時可考慮改用 nvm 管理 Node 版本。

❓ Claude Code 出現「Raw mode is not supported」

請確認是直接在終端機（Terminal.app）或 iTerm2 中執行，而非透過不支援互動式輸入的殼層轉接工具。VS Code 內建的整合式終端機也可以正常使用。

❓ Antigravity CLI 登入後瀏覽器無法自動開啟

手動複製終端機顯示的 URL，貼到瀏覽器網址列即可完成授權。

❓ Antigravity CLI 登入時 Google OAuth 授權失敗，或連線遭封鎖

這是公司網路安全設定造成的封鎖，不是你的操作問題。需要 IT 協助開放以下存取權限：

  • accounts.google.com — Google OAuth 登入
  • oauth2.googleapis.com — OAuth Token 交換
  • generativelanguage.googleapis.com — Gemini API 呼叫
  • agy 執行檔的對外網路存取

請參考 Antigravity CLI 安裝步驟中的 IT Ticket 範本，將錯誤截圖一併附上送出。

❓ Codex CLI 登入時顯示「Sign-in could not be completed」或連線遭封鎖

這是公司網路安全設定造成的封鎖，不是你的操作問題。需要 IT 協助開放以下存取權限：

  • auth.openai.com — OAuth 登入認證
  • api.openai.com — Codex CLI API 呼叫
  • codex 執行檔的對外網路存取

請參考 Codex CLI 安裝步驟中的 IT Ticket 範本，將錯誤截圖一併附上。
