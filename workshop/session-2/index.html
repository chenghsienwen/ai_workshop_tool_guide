SESSION 2

Content First, Visual Follows

AI 輔助簡報製作 — 用 Markdown 與 Slidev 做出符合品牌規範的簡報

PART 1
環境設置與素材準備
開啟會前會建立的 slidev 專案，讓簡報伺服器跑起來
1

下載練習用的 slides.md

從 課程資源檔（slides.md）下載範例檔案，並用它取代會前會建立的 slidev 專案裡的 slides.md。

ℹ️ 會前會沒有完成安裝的話，請先參考首頁的工具安裝指南把 slidev 專案建立起來。
2

用 VS Code 開啟專案

開啟 VS Code 編輯器，左上角點 File → Open Folder，選擇 slidev 資料夾（或你會前會安裝時建立的資料夾名稱，例如 my-slides）。

開啟後，在左側檔案清單中點開 slides.md。

3

（替代做法）直接用終端機／cmd 進入專案資料夾

不透過 VS Code 也可以。直接開啟系統的終端機：

· Windows：按 Win 鍵，搜尋 cmd（命令提示字元）並開啟。
· macOS：按 Cmd + Space，搜尋 Terminal（終端機）並開啟。

接著用 cd 指令進入 slidev 專案資料夾，路徑請換成你實際放專案的位置：

Windows (cmd)
cd C:\Users\你的名字\my-slides
macOS (Terminal)
cd ~/my-slides
ℹ️ 不確定路徑怎麼打？先輸入 cd 加一個空格，再把專案資料夾直接拖曳到終端機視窗，路徑就會自動帶入，按 Enter 即可。

進入資料夾後，下一步的 npm run dev 也可以直接在這個視窗執行，效果與在 VS Code 的終端機中相同。

4

啟動簡報伺服器

在任一種終端機中執行以下指令即可，兩種方式效果相同：

· 使用 VS Code 的話，按 Ctrl + ` 開啟內建終端機（` 這個鍵通常在 ESC 鍵下方），它會自動位在專案資料夾。
· 使用上一步的終端機／cmd 的話，確認已經 cd 進專案資料夾後直接執行。

⚠️ Windows 使用者注意：VS Code 內建終端機預設是 PowerShell，執行本頁指令可能會失敗，請切換成 cmd：點終端機面板右上角 ＋ 旁邊的下拉箭頭 ˅，選擇 Command Prompt 開啟新的終端機再執行。
Terminal
npm run dev

終端機會顯示簡報伺服器的網址，預設是 http://localhost:3030。

❓ 執行 npm run dev 出現錯誤？

最常見的原因是還沒安裝依賴套件。先執行 npm install 等它跑完，再重新執行 npm run dev。

5

用瀏覽器確認簡報畫面

開啟瀏覽器，前往終端機顯示的網址，就能看到簡報頁面。

http://localhost:3030

看到簡報的封面就代表伺服器啟動成功了。之後每次修改 slides.md 存檔，畫面都會即時更新。

⚠️ 3030 是預設的 port。如果被占用，slidev 會改用其他 port，請以終端機實際顯示的網址為準。
PART 2
小試身手：從零開始做一份簡報
跟著七個小步驟，體驗用 Markdown 疊出一整份簡報

先把 slides.md 裡現有的內容全部刪除，我們從一個空白檔案重新開始。以下每一步都是「複製區塊 → 貼到 slides.md 最下方 → 存檔看結果」。

1

做出封面

先決定標題與封面頁面。複製以下內容貼到 slides.md：

slides.md
---
layout: cover-ld
variant: 1
speaker: ProAV Ace （請各位自行替換自己的名字）
date: "2026.08"
theme: proav
---

# 2026.08 期中報告

這個月表現亮眼

layout 指的是簡報的版型；variant 是同一個版型中的不同變種（例如 cover-ld 的 variant: 1 和 variant: 2 會有不同的圖片設定）。

2

做出標題＋內容的內頁

先試試 PowerPoint 最常見的 title 與 content 組合。接在檔案後面貼上：

slides.md
---

# 本季回顧重點
發生好多事情，我們來回顧一下

1. 新產品發表
2. 各個月份的銷售表現
3. 客戶回饋
4. 市場趨勢
5. 未來展望

· --- 是分隔線，用來分隔不同的投影片，之後也會在裡面放當頁投影片的設定。
· # 是標題，緊跟在下一行的文字會變成副標題。
· 1. 開頭的是有序列表。就算你打 1, 2, 4, 5, 6，顯示時還是會自動照 1. 2. 3. 4. 5. 排序。

3

加上表格

來一點點圖表——先從表格開始就好，先不要太刺激：

slides.md
---

# 這季的每月 DAU 表現

| 月份 | DAU | 新增用戶 | 活躍天數 |
| --- | --- | --- | --- |
| 1 月 | 100 | 30 | 22 |
| 2 月 | 200 | 45 | 24 |
| 3 月 | 300 | 60 | 27 |
ℹ️ 目前的表格樣式是 R&D 預先定義好的暫時 placeholder，後續有需要可以再開發更多樣式供大家選擇。
4

換個雙欄版型，放上圖片

先下載這兩張圖片：product-placeholder.png 與 feedback-placeholder.png。

在專案裡新建一個資料夾，取名 assets，把兩張圖片放進去，然後貼上：

slides.md
---
# 本季重點

::left::
## 新產品發表
![新產品發表](./assets/product-placeholder.png)

- 感謝各方援助，才能順利上線
- 上線之後 DAU 超過 100,000 人
- 預計明年 Q1 推出新功能

::right::
## 客戶回饋
![客戶回饋](./assets/feedback-placeholder.png)

1. 最為人詬病的問題是什麼？
2. 我們有什麼解決方案？
3. 未來展望

::left:: 與 ::right:: 會把內容放進版型的左右兩個區域，從左邊講到右邊。

❓ 圖片沒有顯示出來？

確認 assets 資料夾建立在專案根目錄（與 slides.md 同一層），且檔名與 markdown 裡的路徑完全一致。

5

加一個章節轉場

幫投影片加上一個小轉場。這頁就是很單純地套用原本 PowerPoint template 裡就有的 chapter 版型：

slides.md
---
layout: chapter
---

# One More Thing
有一些小驚喜跟大家分享
6

試試全置中版型

除了 PowerPoint template 原有的版型，也有額外製作一些常用版型，像是全置中的 center：

slides.md
---
layout: center
---

哎呀，其實也沒有什麼，這季大家辛苦了，下季再接再厲！<sub>請大家吃下午茶</sub>
7

加上結尾頁

最後是結尾，跟 chapter 一樣，單純套用版型而已：

slides.md
---
layout: end
---

# Thanks
✅ 到此我們已經用純 Markdown 疊出一份封面、內頁、表格、雙欄圖文、轉場到結尾都齊全的簡報，而且每一頁都自動符合品牌視覺規範。
8

匯出與分享

簡報做完之後，開啟瀏覽器到 http://localhost:3030/export（3030 請換成你實際的 port），就能把簡報匯出成 PDF 或 PPTX 等格式。

要分享給同事的話，可以在測試伺服器開啟的狀態下，把簡報連結分享給同事直接瀏覽；如果需要公開，則可以部署到伺服器上提供公開連結。

PART 3
來點 AI 魔法：從資料變成簡報
讓 AI 讀 Excel 記帳資料，直接產出一份旅費報告簡報
1

下載題材：旅費記帳 Excel

從課程資源檔（trip-expenses.xlsx）下載範例資料——9 天京都東京旅費流水帳，約 200 筆記錄。

下載後，把檔案拖曳到 slidev 專案的根目錄中（與 slides.md 同一層）。

2

對 AI 詠唱咒語

開啟你慣用的 AI 工具（Claude Code、Claude Desktop 等皆可），複製這段指令，讓 AI 幫你做出前 4 頁簡報：

Prompt
請讀取 trip-expenses.xlsx(9 天京都東京旅費記錄，總預算 NTD 105,000),
新增一個 trips.md 的投影片，幫我做出前 4 頁簡報：

1. 封面：標題「2026 春・京都東京 9 天旅費報告」，layout: cover
2. 旅程總覽：總花費、天數、每日平均、與預算差額，4 個大數字逐一浮現
3. 錢花去哪了：各分類花費佔比，用 <PieChart> 元件
4. 每天花多少：逐日花費長條圖，標出花最多的一天

金額一律用「臺幣」欄位加總。先做這 4 頁就好，做完等我確認再繼續。
ℹ️ 指令中已經先定好頁數、每頁內容與資料來源欄位，並要求 AI 做完先停下來等確認——不要奢望一次到位，分段迭代才是穩定的做法。
3

開啟 AI 產出的簡報

AI 完成後，在終端機執行：

Terminal
npx slidev --open trips.md

再開啟瀏覽器到 http://localhost:3030，查看 AI 做出來的旅費報告。

⚠️ 請抽查幾個數字是否與 Excel 一致，特別是總花費。AI 產出的結果要由人做最後把關。
4

針對產出進行微調

接下來可以針對 AI 給我們的產出去進行微調。AI 生成長文本時，「AI 味」很容易被察覺，用詞跟句型一定要小心檢查。可以嘗試這些追加指令：

幫我把總覽的數字放大
第 4 頁表格改成長條圖

換版型甚至不用 AI——把某一頁的 frontmatter 改成 layout: center，一行就換了視覺。

ℹ️ Rule of Thumb：如果你知道要改什麼，而且改的時間只需要 1～3 分鐘（例如把「視頻」改成「影片」、換一個 layout），就不要交給 AI 處理，人來比較快。
5

自由發揮：完成後 2 頁

目標是六頁「旅費報告」。前 4 頁跟著做，後 2 頁自由發揮：

· 有趣的發現 — 讓 AI 從資料裡挖 2～3 條洞察
· 結語 — 下次預算抓多少？

✅ 到此我們完成了「內容由人與 AI 一起決定，視覺交給事先定義好的規範」的完整簡報流程。AI 工具可以替換，簡報流程保持一致。
❓ Markdown 語法還不熟，會不會跟不上？

Markdown 不一定要現在學會，先掌握最基本的語法，剩下的交給 AI。不懂或想學進階用法，直接問 AI 就對了，也歡迎來 software R&D 這區找我們聊聊！

❓ Slidev 主題會跟著 PowerPoint template 更新嗎？

會。PowerPoint template 更新時，slidev 主題也會跟著對齊，只是可能會慢個幾天，視更新幅度而定。歡迎提供各種使用建議，我們會儘量滿足大家開出來的需求。
